Formatter for Python, using Black engine.
This engine is bundled with the formatter.

As you can see in the file "_black_version.py", Black version is 25.1.
This version requires Python 3.9 or newer. So it cannot work with preinstalled
Python 3.8 on CudaText Windows version, so on Windows you must install the newer
Python engine from CudaText Addons-Manager.
